Upload Freetrade Screenshots

Upload screenshots of the Freetrade Investments list. The app reads each holding's name, ticker, shares, value and return % on your device, then shows you a review table before anything is imported.

Tip: use Freetrade → Portfolio → Investments. For long lists, scroll and take several screenshots. The OCR engine (Tesseract.js) is downloaded the first time you run it, so you need an internet connection then. Images are never uploaded anywhere.

Review parsed holdings

Rows marked Check are unticked until you've looked at them. Every field is editable. OCR can mix up characters such as O/0 and drop minus signs, so compare the Return % column with your phone. For New holdings you can tick Core hold to protect them from CGT harvesting; existing holdings keep their current setting (change it on the Dashboard).
